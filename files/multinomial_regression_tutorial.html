Introduction: What is a Multinomial Logistic Regression?

If you've heard of regression models but aren't sure, you've probably encountered linear regressions. These are statistical models that try to relate two continuous quantities to each other, so that knowing one lets you guess the other. The typical example would be a linear regression linking weight to height; it should come as no surprise that the taller a person is, the heavier they tend to be. Of course this is a tendency, not an iron law of nature, which is why regression models can be more or less good at predicting. In some cases, you might want the prediction to be based on a categorical variable, for example predicting height based on sex
Sometimes the variable we are trying to predict is not a continuous quantity like height but a category or a label. In the simplest cases, there are only two such categories, for instance 'smoker' or 'non-smoker', 'yes' or 'no'. In this case, the go-to regression is the logistic regression which, instead of directly predicting outcomes, tries to predict the probability of one of the outcomes (the other outcome being complementary, knowing one probability is sufficient), or to be exact, the log-odds of this reference outcome : log(p/(1-p))

A small simulated dataset

Before building the regression model, let's create some synthetic behavioural data. This lets us work through the complete analysis without relying on a particular experimental dataset.
We'll simulate an experiment with three levers. On every trial, the animal chooses one of the three levers and either receives a reward or not.
We'll also divide the experiment into several sessions. This is important because when we construct predictors based on previous trials, we don't want the history from the end of one session to become the history for the beginning of the next session.
%% Simulate some behavioural data
 
rng(1); % make the example reproducible
 
n_subjects = 5;
n_sessions = 4;
trials_per_session = 100;
 
% Columns:
% 1 = subject
% 2 = group
% 3 = session
% 4 = trial number within session
% 5 = unused
% 6 = choice
% 7 = reward
 
data = [];
 
for subject = 1:n_subjects
% Give each subject a group (1 or 2)
group = 1 + (subject > n_subjects/2);
for session = 1:n_sessions
% Simulate choices
choices = randi(3, trials_per_session, 1);
% Give each lever a different probability of reward
reward_probability = [0.7 0.5 0.3];
rewards = zeros(trials_per_session, 1);
for t = 1:trials_per_session
rewards(t) = rand < reward_probability(choices(t));
end
% Trial number within the session
trial = (1:trials_per_session)';
% Assemble this session
session_data = [ ...
repmat(subject, trials_per_session, 1), ...
repmat(group, trials_per_session, 1), ...
repmat(session, trials_per_session, 1), ...
trial, ...
zeros(trials_per_session, 1), ...
choices, ...
rewards ...
];
data = [data; session_data];
end
end
For this example, data has the same basic structure as the experimental data used later in the tutorial:

The last two columns contain the behavioural variables we are interested in:
choices = data(:,6);
rewards = data(:,7);
For example, a sequence such as
Choice: 1 2 1 3 1
Reward: 1 0 1 0 1
means that the animal chose Lever 1 and was rewarded, then chose Lever 2 and was not rewarded, and so on.Constructing the lagged predictors
We now ask whether these previous choices and rewards can predict the choice on the current trial.
Let's use the previous five trials as predictors:
horizon = 5;
n_levers = 3;
ref_lever = 3;
There are two dummy variables for previous choice because Lever 3 is our reference category:
choice_1
choice_2
There are then three variables describing rewarded choices:
reward_1
reward_2
reward_3
Therefore, each lag contributes five columns to our design matrix:
non_ref_levers = setdiff(1:n_levers, ref_lever);
 
n_choice_cols = n_levers - 1;
n_reward_cols = n_levers;
 
cols_per_lag = n_choice_cols + n_reward_cols;
n_pred = cols_per_lag * horizon;
We can now construct X and y subject by subject.
subjects = unique(data(:,1))';
 
for subject = subjects
% Extract this subject's data
rat_data = data(data(:,1) == subject,:);
choices = rat_data(:,6);
rewards = rat_data(:,7);
sessions = unique(rat_data(:,3));
n_sessions = length(sessions);
numTrials = length(choices);
% We lose the first 'horizon' trials of every session because
% there is not enough previous history to construct the predictors.
n_rows = numTrials - horizon * n_sessions;
X = zeros(n_rows, n_pred);
y = zeros(n_rows, 1);
row = 1;
for t = 1:numTrials
trial = rat_data(t,4);
% Skip the first 'horizon' trials of each session
if trial <= horizon
continue
end
% Current choice is the response variable
y(row) = choices(t);
% -------------------------------------------------------------
% Construct predictors from previous trials
% -------------------------------------------------------------
for k = 1:horizon
% First column belonging to this lag
lag_offset = (k-1) * cols_per_lag;
past_choice = choices(t-k);
past_reward = rewards(t-k);
% ---------------------------------------------------------
% Previous choice
% ---------------------------------------------------------
% Lever 3 is the reference category, so it does not get
% its own dummy variable.
if past_choice == 1
X(row, lag_offset + 1) = 1;
elseif past_choice == 2
X(row, lag_offset + 2) = 1;
end
% ---------------------------------------------------------
% Previous rewarded choice
% ---------------------------------------------------------
% If the previous choice was rewarded, activate the
% indicator corresponding to the chosen lever.
if past_reward == 1
reward_col = lag_offset + ...
n_choice_cols + past_choice;
X(row, reward_col) = 1;
end
end
row = row + 1;
end
% Fit the multinomial logistic regression
[B, dev, stats] = mnrfit(X, y);
if subject == 5
figure()
plot(B(:,1))
end
end
We now have a completely self-contained example of the analysis. The design matrix contains the animal's behavioural history, while y contains the choice made on the current trial.
For horizon = 5, there are:
5 predictors per lag × 5 lags = 25 predictors
so X has 25 columns.
The first five columns describe the immediately preceding trial, the next five describe the trial before that, and so on.
This gives us a model of the form:
Current choice
↑
│
├── choice 1, 1 trial ago
├── choice 2, 1 trial ago
├── reward on lever 1, 1 trial ago
├── reward on lever 2, 1 trial ago
├── reward on lever 3, 1 trial ago
│
├── choice 1, 2 trials ago
├── choice 2, 2 trials ago
├── ...
│
└── history from 5 trials ago
The coefficients estimated by mnrfit therefore tell us how each component of recent behavioural history is associated with the probability of making each of the three possible choices on the current trial.
